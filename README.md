# Terra Table
Buildless interactive meal-prep concept. Serve `dist` with a static server.

Real WebGL Earth with local Three.js dependency, Earth day/normal/specular textures, atmospheric rim, procedural cloud layer, draggable rotation, zoom, geographic raycasting, curated destination pins, meal filters, local saved places, a meal box and demo plan summary. Menus, prices and nutrition are illustrative. Surface clicks choose the closest curated cuisine, not political country boundaries. No real commerce, payment or delivery integration. Local browser storage only.

Assets: Three.js (MIT), Earth textures from the Three.js examples collection; illustrative food photos from Unsplash. Texture and dependency source URLs are recorded in ASSETS.md. Browser QA was unavailable in this environment; JavaScript syntax and static asset validation completed.
